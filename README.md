Geotechnical Soil Stress Analysis
A Python project for analyzing and visualizing basic soil stress components in geotechnical engineering.

Features
*Calculation of total stress 
*Calculation of pore water pressure
*Calculation of effective stress 
*Data handling using Pandas 
*Data visualization using Matplotlib

Tools
*Python
*Pandas
*Matplotlib

Application
This project demonstrates the use of Python for basic geotechnical engineering calculations and visualization of soil stress profiles.
