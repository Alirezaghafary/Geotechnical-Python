Geotechnical Engineering Analysis with Python

This repository contains Python-based geotechnical engineering calculations and data visualization.

Projects

1. Soil Stress Analysis

Calculation and visualization of:

- Total vertical stress
- Pore water pressure
- Effective stress

Files:

- "soil_stress_analysis.py"
- "soil_stress_analysis.png"
- "soil_stress_table.csv"

2. Consolidation Settlement

Calculation of one-dimensional consolidation settlement using soil consolidation parameters.

Files:

- "consolidation_settlement.py"
- "consolidation_settlement.png"
- "consolidation_settlement_table.csv"

3. Slope Stability Analysis

Calculation of slope Factor of Safety using geotechnical soil parameters.

Files:

- "slope_factor_of_safety.py"
- "slope_factor_of_safety.png"
- "slope_factor_of_safety_table.csv"

Python Libraries

- NumPy
- Pandas
- Matplotlib

Purpose

The purpose of this repository is to demonstrate the application of Python programming to geotechnical engineering calculations, numerical data processing, and engineering visualization.
